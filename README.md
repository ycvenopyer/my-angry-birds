# 🐦 Angry Birds 愤怒的小鸟

一个使用原生 **HTML + Canvas + Matter.js** 物理引擎实现的单文件《愤怒的小鸟》风格游戏。拖拽弹弓、蓄力、松手，用抛物线轰塌积木建筑、炸飞绿色小猪！

## ✨ 功能特性

- **拖拽瞄准发射**：按住弹弓上的小鸟向后拖，白色虚线实时预览飞行轨迹，松手即发射
- **真实物理模拟**：Matter.js 驱动重力、碰撞、摩擦与空气阻力，建筑倒塌、碎块横飞都有真实反馈
- **伤害判定系统**：
  - 小鸟以高速撞击小猪 / 积木时按碰撞速度计算伤害
  - 被砸塌的建筑（碎块）也能砸伤小猪
  - 小猪从高处坠落同样受伤
- **计分系统**：每摧毁一只小猪 +10 分，带飘字特效；顶部 HUD 实时显示得分与剩余小鸟
- **六种小鸟技能**：
  | 颜色 | 技能 | 触发方式 | 说明 |
  |------|------|----------|------|
  | 🔴 红色 | 普通 | — | 圆形炮弹，基础碰撞伤害 |
  | 🟡 黄色 | 冲刺加速 | 按 `R` / 右键 | 沿当前飞行方向猛冲，速度 ×24 |
  | 🔵 蓝色 | 一分为三 | 按 `R` / 右键 | 分裂为 3 只小鸟散射，覆盖更大范围 |
  | ⚫ 黑色 | 爆炸冲击 | 按 `R` / 右键 | 以自身为圆心引爆，炸飞半径 90px 内所有猪和积木 |
  | ⚪ 白色 | 空投炸弹 | 按 `R` / 右键 | 向下方丢一颗炸弹蛋，触地 / 撞目标即引爆 |
  | 🟢 绿色 | 回旋折返 | 按 `R` / 右键 | 飞行方向反转、速度 ×1.6（每只限 1 次），杀回马枪 |

- **猪的装甲系统**：
  | 类型 | 图示 | 血量 | 头部减伤 | 出现关卡 |
  |------|------|------|----------|----------|
  | `normal` | 普通绿猪 | 22 | 0% | 第 1 关起 |
  | `helmet` | 木盔猪 🪵 | 30 | 40% | 第 3 关起 |
  | `armored` | 铁盔猪 ⛓️ | 40 | 70% | 第 4 关起 |

  头盔仅在**撞击猪头部**（碰撞点位于圆心上半部）时生效，击中身体不减伤。铁盔猪头部有银色铆钉装饰。

- **20 个关卡**：难度梯度递增，分四个难度层级
  | 区间 | 关卡 | 猪数 | 猪类型 | 积木数 | 背景 |
  |------|------|------|--------|--------|------|
  | 入门 (1-3) | 初出茅庐 → 石头堡垒 | 2-3 | normal + helmet | 4-8 | 晴空 |
  | 进阶 (4-5) | 铁甲初现 → 要塞攻坚 | 5-6 | armored 登场，全类型混合 | 8-9 | 黄昏/清新绿 |
  | 挑战 (6-10) | 双塔奇兵 → 终极试炼 | 4-6 | armored 为主 | 8-11 | 三色循环 |
  | 地狱 (11-20) | 迷宫石阵 → 终局之战 | 5-9 | 几乎全 armored，第20关 9 只铁盔猪 | 11-14 | 含紫夜新背景 |

  每关小鸟配置独立，低关卡 3-4 只鸟入门，高关卡固定 6 只（全种类），通关后循环回第 1 关。
- **卡通视觉**：Canvas 手绘红鸟、绿猪、木石积木，含受击白闪、爆炸粒子、镜头抖动、胜利星级结算
- **音效合成**：Web Audio API 实时合成发射、撞击、爆炸、胜利音效，可一键静音

## 🎮 如何游玩

```text
① 拖住弹弓上的小鸟向后拉（离锚点越远，射得越有力）
② 观察白色瞄准虚线，估算抛物线落点
③ 松手发射！
④ 瞄准建筑弱点，让倒塌的积木砸中小猪
⑤ 飞行中按 R 键 / 右键 / 空格触发小鸟特殊技能
⑥ 摧毁全部小猪即可过关
```

**触屏设备**：直接手指拖拽；飞行中点击屏幕上的「✨ 特殊技能」按钮触发技能。

## 🚀 运行方式

**方式一：本地服务器（推荐）**

```bash
cd my-angry-birds
python -m http.server 8000
# 浏览器打开 http://localhost:8000/angry-birds.html
```

**方式二：直接双击** `angry-birds.html` 打开。

> ⚠️ 需要联网访问 jsdelivr CDN 加载 Matter.js 物理引擎。若离线，请下载 [matter-js](https://cdn.jsdelivr.net/npm/matter-js@0.19.0/build/matter.min.js) 到本地并修改 `<script>` 标签指向本地文件。

## 🧱 技术架构

| 模块 | 说明 |
|------|------|
| **渲染** | Canvas 2D，`devicePixelRatio` 适配高清屏；静态背景（蓝天/云/山/草）预渲染到离屏画布，逐帧只绘制动态物体 |
| **物理** | Matter.js `Engine` 固定步长（60Hz）驱动，自定义重力、材质密度、摩擦与空气阻力 |
| **游戏状态机** | `idle → ready → drag → flying`，管理拖拽、发射、回合结算与胜负判定 |
| **伤害模型** | 碰撞事件监听 + 相对速度计算伤害；木块一击可碎（hp=1），石条需多次命中（hp=3）|
| **装甲系统** | 碰撞点位于猪圆心上半部判定为头部，触发 `helmet` 减伤系数；`armored` 铁盔 70% 减伤 |
| **爆炸物理** | 黑鸟爆炸 / 白鸟蛋爆炸：对半径内物体施加冲击力 + 伤害，推开并震碎建筑 |
| **关卡配置** | `LEVELS` 数组声明式定义每关小鸟队列、猪类型位置、积木布局与背景色，易扩展 |
| **音效** | Web Audio 实时合成，无外部音频资源 |

## 🎯 游戏数值（可调参数）

游戏开头的常量决定了手感，可按喜好修改：

```js
const PULL_MAX  = 112;   // 最大拖拽距离（力度上限）
const LAUNCH_K  = 0.34;  // 拖拽距离 → 发射速度的系数
const GROUND_Y  = 560;   // 地面高度

// 猪属性（按类型）
const PIG_TYPE_HP     = { normal:22, helmet:30, armored:40 };   // 血量
const PIG_TYPE_HELMET = { normal:0,  helmet:0.4, armored:0.7 }; // 头部减伤比例

// 积木破坏阈值
const BREAK_FORCE = { wood: 5.5, stone: 9 };   // 碰撞速度超过此值即一击粉碎
```
